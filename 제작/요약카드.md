# 초심자 요약 카드

> 한 장에 들어가게 쓴 요약이다. 자세한 건 [게임 진행 순서](../규칙/진행순서.md).

**목표**: 남의 성을 함락해 마지막까지 남거나, 20년째 연말에 승점 1등 (땅 1, 성 함락 10, 자기 성 5).

**준비**: 종족 고르기 → 곡식 7~10 + 지역 카드(+3/0/-2) → 원하는 칸에 성 → 정복도 5칸.

**1년 = 행동 2번** (하나 골라서):
- 탐사: 옆 칸 차지 (정복도 강·육지 1칸, 산·바다 2칸)
- 군대 양성 (곡식 2 = 1명) · 이동 (군대 수만큼 주사위, 최대 6개)
- 건설 (다리 5, 요새 20) · 동맹 · 선전포고 · 상점
- 탐사 말고 다른 행동을 하면 정복도 +2칸

**전투**: 주사위 4개 → 내 스탯 4개에 배치 → (스탯 × 주사위) 합이 큰 쪽 승리. 군대가 많으면 다시 굴리기. 소모전엔 전술 카드.
- 소모전 지면 군대 절반, 총력전 지면 전부와 그 칸. 성 칸에서 이기면 함락.

**연말 순서**: 유지비(군대 10명당 1) → 세금(칸 수만큼) → 광산·곡창 → 상인 → 이념 → 카드(기후·기후·재앙).

**망하면**: 첫 번째는 마왕, 그다음부터는 마왕 편. 좀비와 [마왕 카드](../카드/마왕카드.md)로 계속 플레이.
