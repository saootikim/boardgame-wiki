# 부품

## 만들어야 할 것
- ~~지도(게임판)~~ → [보드판](보드판.md) (초안 완성)
- 다리(강용), 배·항구(바다용)
- 광산 카드, 상인의 마을 카드 ×2, 바다의 신전(심해용)
- 재앙·기후 카드, 지역 카드, 종족 카드
- 정복도 표시판, 개인칸
- 곡식(자원), 요새, 기본카드(자원), 기본 규칙 카드(초심자용), 주사위

## 부품 아이디어
- **개인칸(개인판)**: 미리 만들어 두고 시작함. 이름, 종족(동그라미), 곡식 칸, 정복 칸 (요런 느낌).
- **종족 토큰**: 앞면은 종족 그림 + 배경, 뒷면은 "?". 아니면 카드로.
- **곡식**: 1 / 10 / 100 자루. 아니면 카드로. (0 하나를 뗀 단위. 인쇄한 곡물 카드 10~1000은 10으로 나눠 읽거나 다시 인쇄)
- **정복도**: 개인판에 0~5칸 눈금 트랙을 두고 큐브 1개로 표시.
- **군사**: 맵 1칸 크기 타일로 +1, +5 … +100. → [카드와 군사 유닛](카드와유닛.md) (완성)
