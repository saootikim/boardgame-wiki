# 게임 만들기 프롬프트 (Claude Code용)

이 보드게임을 브라우저에서 "나 vs 컴퓨터"로 칠 수 있는 게임으로 만드는 프롬프트다. 이 폴더(vault 루트)에서 Claude Code를 열고 아래 블록을 그대로 붙여 넣는다.

````text
<context>
이 폴더는 친구들과 만드는 보드게임의 Obsidian vault다. 규칙은 전부 노트에 있고, 숫자는 모두 임시값이다.
규칙의 원본은 노트다. 노트와 아래 요약이 다르면 노트를 따른다.

- 규칙: 규칙/기본규칙.md, 규칙/진행순서.md, 규칙/전쟁.md
- 세계: 세계/종족.md (8종족 스탯·처음 곡식·고유 능력), 세계/지형.md, 세계/이념카드.md
- 카드: 카드/전술카드.md (24장), 카드/재앙카드.md, 카드/기후카드.md, 카드/지역카드.md, 카드/마왕카드.md
- 지도 데이터: 제작/지도.txt (35×23 글자 지도, 글자 = 지형 코드, 범례는 파일 맨 위)
- 지도 그림: 세계/격자 진하게/ 의 PNG 4장 (각 3072×2048). 붙이는 순서와 방법은 제작/지도_인쇄.py 에 있다.
- 카드 그림: 카드/*.png. 한 그림에 카드 여러 장이 들어 있는 시트다. 자르는 위치는 제작/카드_만들기.py 의 SOURCES 를 참고한다. 카드 뒷면은 카드/카드뒷면.png, 마왕 카드 뒷면은 카드/마왕카드_뒷면.png.
- AI 참고: 제작/시뮬레이션.py 에 컴퓨터 플레이어 행동 규칙과 전투 판정이 이미 Python으로 있다. 이것을 JavaScript로 옮겨 컴퓨터 플레이어로 쓴다.
</context>

<task>
`게임/` 폴더에 브라우저에서 바로 열리는 1인용 게임을 만든다. 사람 1명 + 컴퓨터 3명(4나라).
index.html 을 더블클릭하면 서버 없이 실행되어야 한다 (file:// 에서 동작, 외부 CDN 없음, 빌드 도구 없음).
</task>

<rules_to_implement>
노트를 읽고 다음을 전부 구현한다:
1. 준비: 종족 선택(사람만 고름, 컴퓨터는 무작위), 처음 곡식 + 지역 카드(+3/0/-2), 성을 놓을 칸 고르기(클릭), 정복도 5칸.
2. 1년: 나라마다 행동 2번. 탐사(칸 차지, 지형별 정복도), 군대 양성(곡식 2), 군대 이동(군대 수만큼 주사위, 최대 6, 주사위 합만큼 칸), 공격, 쉬기. 탐사가 아닌 행동은 정복도 +2칸.
3. 원주민(미개발지), 바다의 신전, 버뮤다 삼각지대: 노트에 적힌 임시 효과 그대로.
4. 전투: 주사위 4개 → 병력 차이 다시 굴리기 → 소모전이면 전술 카드 동시 공개 → 주사위를 스탯 4개에 배치 → (스탯×주사위) 합. 사람은 주사위를 직접 드래그나 클릭으로 배치한다. 컴퓨터는 큰 주사위를 큰 스탯에 놓는다. 전투 화면에 양쪽 계산식을 보여 준다.
5. 소모전·총력전 패배 손실, 성 함락, 함락 시 흡수(땅·곡식·남은 군대 절반), 패권국.
6. 연말: 세금(땅 칸 수), 곡창 +5, 광산 전술 카드, 군대 유지비, 곡식 빚, 이념 카드, 기후 → 기후 → 재앙 순서 카드 뽑기.
7. 마왕: 처음 망한 나라가 마왕, 이후 망한 나라는 마왕 편. 좀비 1:1, 좀비 3/3/3/3, 저주 카드. 사람이 망하면 마왕으로 계속 플레이한다.
8. 끝: 혼자 남음 / 마왕이 모두 없앰 / 20년째 연말 승점(땅 1, 성 함락 10, 자기 성 5).
노트에 효과가 없거나 "미정"인 카드는 "효과 미정" 표시만 하고 아무 일도 일어나지 않게 한다. 규칙을 새로 지어내지 않는다.
</rules_to_implement>

<design>
- 지도: 실사 지도 4장을 하나로 붙여 배경으로 쓰고, 그 위에 지도.txt 칸 격자를 맞춰 얹는다. 나라 땅은 반투명 나라 색, 성은 굵은 아이콘, 군대는 숫자가 적힌 말. 마우스를 올리면 칸 지형과 주인이 보인다. 그림과 격자가 안 맞으면 그림 대신 지도.txt 색 칸으로 그린다.
- 카드: 손패·뽑은 카드·전술 카드 공개는 실제 카드 그림을 잘라서 보여 준다. 카드 효과 글씨는 노트 표에서 가져와 그림 아래에 붙인다.
- 화면: 가운데 지도, 오른쪽 내 나라 정보(곡식·정복도 0~5칸 트랙·군대·땅·손패), 아래 행동 버튼과 기록(누가 무엇을 했는지). 컴퓨터 차례는 0.5초 간격으로 보여 주고 "건너뛰기" 버튼을 둔다.
- 모든 글자는 한국어. 1280×720 이상 화면 기준.
</design>

<constraints>
- 수정은 `게임/` 폴더 안에서만 한다. 노트(.md), 기존 스크립트, 이미지 원본은 읽기만 한다. 그림은 `게임/assets/` 로 복사해서 쓴다.
- 새 패키지를 설치하지 않는다. 순수 HTML·CSS·JavaScript만 쓴다.
- 규칙 숫자는 한 파일(`게임/rules.js`)에 모아서 나중에 바꾸기 쉽게 한다.
- 요청한 것만 만든다. 온라인 대전, 저장 기능, 소리, 로그인은 넣지 않는다.
- 노트끼리 규칙이 어긋나면 고르지 말고 멈춰서 어떤 노트의 어떤 줄이 어긋나는지 물어본다.
</constraints>

<done_when>
1. index.html 을 열면 종족 선택 → 성 놓기 → 1년차 차례로 진행된다.
2. 사람이 탐사·양성·이동·공격을 할 수 있고, 전투에서 주사위를 직접 배치할 수 있다.
3. 컴퓨터 3나라가 스스로 행동하고, 20년 안에 게임이 끝나고 승자 화면이 나온다.
4. 연말 카드(기후·재앙)와 전술 카드가 실제 카드 그림으로 보인다.
5. 사람이 망하면 마왕으로 이어서 할 수 있다.
6. 브라우저 콘솔에 오류가 없다.
</done_when>

<report>
끝나면 다음만 짧게 알려 준다: 만든 파일 목록, 구현한 규칙과 못 한 규칙(이유 포함), 노트에서 찾은 모순이나 빈칸, 직접 한 판 쳐 보며 확인한 것.
</report>
````

> [!WARNING]
> 이 프롬프트는 파일을 만들고 고치는 에이전트용이다. 붙여 넣기 전에 `게임/` 폴더만 고치도록 범위가 맞는지 확인한다.
