# 전술 카드

> [!WARNING] 밸런스 미정
> 이 노트의 숫자는 전부 임시값이다. 테스트하면서 맞춘다.

- 상점에서 삼.
- 소모전에서 주사위를 굴린 뒤, 배치하기 전에 1장을 뒤집어 내고 동시에 공개한다. 총력전에서는 사용 불가.
- 카드는 스탯 하나를 올린다. 상성에서 이기면 같은 스탯을 +2 더 올린다.
- 판정 순서: [전쟁](../규칙/전쟁.md).

## 상성
계열 4개는 스탯 4개와 짝이다.

**공격**(공격력) > **책략**(지능) > **기동**(정복력) > **방어**(HP) > **공격**

## 카드 24장 (계열마다 6장)

| 카드 | 계열 | 효과 |
|---|---|---|
| 정면 공격 | 공격 | 공격력 +2 |
| 돌격 | 공격 | 공격력 +3. 지면 군대 70%를 잃음 |
| 기습 | 공격 | 공격하는 쪽일 때만 공격력 +4 |
| 방진 | 방어 | HP +2 |
| 농성 | 방어 | 내 성·요새 칸에서 막을 때 HP +4 |
| 후퇴 | 방어 | HP +0. 지면 군대 25%만 잃음 |
| 계략 | 책략 | 지능 +2 |
| 매복 | 책략 | 정글·산 칸에서만 지능 +4 |
| 첩보 | 책략 | 지능 +1. 주사위 1개를 다시 굴림 |
| 측면 공격 | 기동 | 정복력 +2 |
| 강행군 | 기동 | 정복력 +1. 이기면 옆 칸 1개를 더 차지 |
| 도하 | 기동 | 강·바다를 건너 싸울 때 정복력 +4 |
| 일제 사격 | 공격 | 공격력 +1. 상대 HP -1 |
| 화공 | 공격 | 정글·곡창지대 칸에서만 공격력 +4 |
| 광전사 | 공격 | 공격력 +4. 내 HP -2 |
| 방패벽 | 방어 | HP +3. 이겨도 옆 칸을 더 차지하지 못함 |
| 참호 | 방어 | 내 땅 칸에서 막을 때 HP +3 |
| 산악 수비 | 방어 | 산 칸에서 막을 때 HP +4 |
| 위장 퇴각 | 책략 | 지능 +1. 상대 카드의 숫자를 절반으로 (내림) |
| 야습 | 책략 | 지능 +2. 상대 주사위 1개를 다시 굴리게 함 |
| 보급 차단 | 책략 | 지능 +1. 진 쪽은 다음 해까지 군대 양성 불가 |
| 기병 돌파 | 기동 | 정복력 +3. 지면 군대 60%를 잃음 |
| 해상 상륙 | 기동 | 바다에서 육지로 공격할 때 정복력 +4 |
| 우회 | 기동 | 정복력 +1. 상대 칸의 요새 효과를 무시 |

카드 그림은 [전술 카드 프롬프트](../제작/전술카드_프롬프트.md)로 뽑는다.
