# 전술 카드

> [!WARNING] 밸런스 미정
> 이 노트의 숫자는 전부 임시값이다. 테스트하면서 맞춘다.

- 상점에서 삼.
- 소모전에서 주사위를 굴린 뒤, 배치하기 전에 1장을 뒤집어 내고 동시에 공개한다. 총력전에서는 사용 불가.
- 카드는 스탯 하나를 올린다. 상성에서 이기면 같은 스탯을 +2 더 올린다.
- 판정 순서: [전쟁](../규칙/전쟁.md).

## 상성
계열 4개는 스탯 4개와 짝이다.

**공격**(공격력) > **책략**(지능) > **기동**(정복력) > **방어**(HP) > **공격**

## 카드 12장

| 카드 | 계열 | 효과 |
|---|---|---|
| 정면 공격 | 공격 | 공격력 +2 |
| 돌격 | 공격 | 공격력 +3. 지면 군대 70%를 잃음 |
| 기습 | 공격 | 공격하는 쪽일 때만 공격력 +4 |
| 방진 | 방어 | HP +2 |
| 농성 | 방어 | 내 성·요새 칸에서 막을 때 HP +4 |
| 후퇴 | 방어 | HP +0. 지면 군대 25%만 잃음 |
| 계략 | 책략 | 지능 +2 |
| 매복 | 책략 | 정글·산 칸에서만 지능 +4 |
| 첩보 | 책략 | 지능 +1. 주사위 1개를 다시 굴림 |
| 측면 공격 | 기동 | 정복력 +2 |
| 강행군 | 기동 | 정복력 +1. 이기면 옆 칸 1개를 더 차지 |
| 도하 | 기동 | 강·바다를 건너 싸울 때 정복력 +4 |
