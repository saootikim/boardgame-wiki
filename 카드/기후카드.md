# 기후 카드

1년마다 뽑음 (기후 → 기후 → 재앙 순환).

- 뽑은 해 1년 동안 모든 나라에 적용된다.
- 처음 6장(비~지중해성)은 친구들이 정한 종류, 나머지 6장은 Claude가 추가한 초안이다.

> [!WARNING] 밸런스 미정
> 효과 숫자는 전부 임시값이다. 테스트하면서 맞춘다.

| 카드 | 효과 |
|---|---|
| 화창함 | 연말 곡식 +2 |
| 비 | 강 탐사 정복도 +1칸. 곡창지대 1칸당 수확 +2 |
| 눈 | 이동 주사위 -1개 |
| 구름 낀 | 효과 없음 (평범한 해) |
| 번개 치는 | 전투에서 막는 쪽이 주사위 1개를 다시 굴림 |
| 지중해성 | 상점 카드 1장당 곡식 -1 |
| 안개 | 소모전에서 전술 카드를 공개 전에 바꿀 수 있음 (뒤집힌 채로 1번) |
| 강풍 | 배 이동·바다 탐사 정복도 +1칸 |
| 가뭄 기미 | 연말 세금 -2 (최소 0, 빚이 있으면 최소 3 규칙은 그대로) |
| 풍년 | 곡창지대·정글 칸 1칸당 곡식 +1 |
| 오로라 | 미개발지 탐사 정복도 0. 원주민 카드를 1장 더 보고 고름 |
| 붉은 하늘 | 다음 재앙 카드를 미리 공개함 (모두가 봄) |
