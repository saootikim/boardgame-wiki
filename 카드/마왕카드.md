# 마왕 카드 (저주)

> [!WARNING] 밸런스 미정
> Claude가 쓴 초안이다. 숫자는 임시값이고 친구들과 확인한다.

- 마왕과 마왕 편 플레이어(두 번째부터 망한 사람)가 쓴다. 탈락한 뒤에도 매년 할 일이 생긴다.
- 연초에 각자 1장 뽑고, 그해 자기 차례에 1번 쓴다. 쓴 카드는 버린다.
- 규칙: [게임 진행 순서](../규칙/진행순서.md#마왕).

| 카드 | 효과 |
|---|---|
| 흉작의 저주 | 나라 1곳의 이번 연말 곡식 -3 |
| 시체 행군 | 좀비 무리 1개가 이번 해 이동 +2칸 |
| 공포 | 나라 1곳은 이번 해 선전포고를 못 함 |
| 역병 | 나라 1곳의 군대 5명이 죽음 (죽은 군대는 좀비가 됨) |
| 배신의 속삭임 | 동맹 1쌍을 골라 이번 해 동맹을 끊음 |
| 무덤 깨우기 | 마계에 좀비 5마리를 새로 놓음 |
