# 지형

> [!WARNING] 밸런스 미정
> 이 노트의 숫자는 전부 임시값이다. 테스트하면서 맞춘다.

## 게임판
- A4 용지 4장을 붙이고 작은 네모 칸으로 나눈 판. 배치와 인쇄 파일: [보드판](../제작/보드판.md).

## 지형지물

| 지형 | 영문 | 효과 |
|---|---|---|
| 강 | The river | 다리를 놓으려면 자원 필요(없으면 곡물). 다리가 없으면 정복도 1칸 |
| 산 | The M.T | "하늘로 취급": 군대가 지나갈 수는 있지만 산 칸에서 멈출 수 없음 (임시, 친구 확인). 정복도 2칸 |
| 바다 | The Ocean | 정복도 2칸. 배를 지으면 1칸으로 감소. 배를 지으려면 바닷가 땅 필요 |
| 광산 | The Mine | 광산 일대를 얻으면 연말 정산마다 카드 1장 |
| 버뮤다 삼각지대 | The Mystery ocean | 섬 3개를 낀 바다. 중립지역. 들어오면 배를 다른 곳으로 이동시킴(아마) |
| 섬 | The land | 강·육지와 같음 |
| 마계 | The heaven | 용암지대. 각 종족의 곡식을 추가로 지불해야 정복 가능 |
| 정글 | The jungle | 그냥 땅 |
| 상인의 마을 | The village of Merchant | 중립지역. 연말에 인접 땅 주변 3칸까지 차지한 왕국은 스페셜 카드를 얻음 |
| 심해 | The deep ocean | 들어가면 바다의 신전이 펼쳐짐. 곡물을 바치면 그만큼 대가를 줌 |
| 미개발지 | The Unknown Place | 주로 남극·북극 쪽. 원주민 있음 ([지역 카드](../카드/지역카드.md)) |
| 곡창지대 | The farm | 곡물 20이나 자원을 내고 차지. 연말마다 1칸당 곡물 5 추가. 전쟁으로 주인이 바뀌면 다시 내야 함 |
